Sekai Soundbar для Windows 11 x64

1. Закройте запущенный док через «Выход» в меню значка Sekai Soundbar
   в трее или по правому клику на доке.
2. Распакуйте весь ZIP и запустите SekaiSoundbar.exe либо запустите установщик.
   Для обновления установленной версии запустите новый установщик.
3. Включите музыку. Док появится на рабочем столе и раскроется, когда
   его область свободна. На паузе команды доступны через значок в трее.
4. Откройте «Настройки…» через трей или по правому клику на доке.
   В разделе «Общие» можно включить автозапуск. В разделе «Мониторы»
   можно отдельно указать, на каких экранах показывать док.
5. В разделе «Оформление» включите «Преломлять фон рабочего стола» для
   стекла с реальным фоном. Если эффект слабо виден, уменьшите
   непрозрачность корпуса. Нажмите «Скрыть жёлтую рамку» и подтвердите
   разрешение Windows, чтобы убрать рамку захвата. Пока преломление
   активно, док исключается из снимков экрана.

При запуске из ZIP держите DLL и папки plugins, qml и alignment рядом с EXE.
Для чтения уведомлений приложений Windows нужна сборка с подписанным пакетом.
Настройки хранятся в профиле Windows. Удаление доступно в «Установленных приложениях».
