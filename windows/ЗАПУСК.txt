Sekai Soundbar для Windows 11 x64

1. Закройте запущенный док через «Выход» в меню по правому клику.
2. Распакуйте весь ZIP и запустите SekaiSoundbar.exe либо запустите установщик.
   Для обновления установленной версии запустите новый установщик.
3. Откройте «Оформление дока…» по правому клику. Включите «Преломлять фон
   рабочего стола» для стекла с реальным фоном. Если эффект слабо виден,
   уменьшите непрозрачность корпуса.
4. Чтобы убрать рамку захвата, в «Оформлении дока…» нажмите «Скрыть жёлтую
   рамку» и подтвердите разрешение Windows. Пока преломление активно, док
   исключается из снимков экрана. Для снимка дока выключите эффект.

При запуске из ZIP держите DLL и папки plugins, qml и alignment рядом с EXE.
Настройки хранятся в профиле Windows. Удаление доступно в «Установленных приложениях».
