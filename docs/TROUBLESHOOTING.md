# Диагностика и ограничения

[← README](../README.md)

## Всё пропало после обновления SekaiPOP

В предварительной **v3** проверьте наличие native API в запущенной оболочке:

```sh
qs -c sekaipop ipc call dockequalizer status
qs -c sekaipop ipc call plugins list
```

Если `nativeIntegration: false`, обновление заменило оболочку с предложенными расширениями или запустилась другая копия. Сверьте версию оболочки с [инструкцией native API](NATIVE-INTEGRATION.md). При `modules.host.state: degraded` список `missing` указывает недоступные возможности. На совместимой оболочке проверьте, что нужное расширение включено и загружено; после завершения записи или анализа можно перезагрузить список через `qs -c sekaipop ipc call plugins reload`. Установщик из v3 ничего не меняет.

Стабильная **v2** использует локальные адаптеры и имеет [отдельную инструкцию восстановления](https://github.com/Aferon-08/sekaipop-dock-equalizer/blob/main/docs/INSTALL.md). Обычный каталог официальной оболочки сможет полноценно загрузить v3, когда в ней появятся нужные поверхности.

## Плагин указан как desktop off

Это статус отдельного виджета рабочего стола. Док и обои подключены независимо. Проверяйте параметры `enabled`, `proceduralWallpaper` и фактические IPC-статусы.

## Капсулы не появились

Проверьте воспроизведение в MPRIS-плеере, доступность CAVA, вывод звука и свободное место по краям дока. При длине менее 64 px капсула скрывается. Блокировка, Game Mode и скрытый док тоже ограничивают работу.

```sh
qs -c sekaipop ipc call dockequalizer status
qs -c sekaipop log -t 100
```

`running: false` при паузе — ожидаемое отключение аудиопотока. При сбое CAVA статус `modules.audio` показывает причину и интервал следующей попытки. Если браузер не публикует MPRIS/длительность/позицию, плагин не может гарантировать полноценное управление. Для YouTube предусмотрено уточнение длительности, но оно также зависит от доступности источника. Временный сбой повторяется автоматически; для текущего видео можно вызвать `qs -c sekaipop ipc call docklyrics-eDP-1 retryDuration`.

В **Dock Equalizer → Звук → Диагностика звука** видны текущий выход, число полос, давность последнего пакета и PID CAVA. При смене выхода плагин привязывается к его монитору. При отсутствии монитора он ждёт появления устройства. **Бесшумная проверка** подтверждает доступность монитора и прогоняет тестовый тон через CAVA в памяти. Её можно запускать на паузе.

```sh
qs -c sekaipop ipc call dockequalizer testAudio
qs -c sekaipop ipc call dockequalizer audioStatus
```

### Позиция песни и перемотка

На мониторах используется одна модель позиции выбранного плеера. `modules.media.clock` в статусе показывает текущую позицию, источник, номер смены трека, пропущенные нулевые чтения и подтверждённые перемотки. При `source: "native"` позиция получена через Quickshell, при `source: "mpris"` — напрямую от плеера. Поле `error` содержит причину сбоя прямого чтения, если доступен запасной источник.

## Нет лирики или несколько голосов распознаны неправильно

Проверьте совпадение версии записи и текста. Данные источника могут не содержать подпевки. Импортируйте более точный JSON или выберите правильный аудиофайл и запросите повторный анализ. Хор/двойная запись одного певца не всегда означают отдельных персонажей.

## Долгий анализ

Стадия голосов может выполнять несколько моделей, поэтому процент прогресса не является линейным таймером. Выберите разумное число CPU-потоков и подготовьте CUDA-окружение при наличии NVIDIA. Уменьшение нагрузки на интерфейс не ускоряет модель на CPU автоматически. Для диагностики:

```sh
qs -c sekaipop ipc call docklyrics-eDP-1 wordtimeStatus
```

Смените имя монитора на своё. Не отменяйте и не перезапускайте задание только потому, что процент некоторое время стоит на месте; сначала посмотрите этап и загрузку CPU/GPU.

## Дёргаются обои или не работает стекло

Если стекло не захватывает окно, смотрите `qs -c sekaipop ipc call dockcapture-eDP-1 status` и `docksettings-eDP-1 status`. `idle` без подходящих окон ожидаем, `recovering` означает ожидание новой попытки.

Нужен аппаратный Qt Quick renderer. Программный renderer/llvmpipe не является целевой конфигурацией. Проверьте драйверы и способ запуска самой оболочки. При PRIME желательно понимать, какая GPU рисует весь процесс: плагин не переносит отдельные QML-объекты на другую GPU. Переменные для CUDA-анализа этого не меняют.

Для снижения нагрузки отключите движение фигур, затем питомца. Высокий DPI, несколько мониторов, стеклянные слои и большая площадь текстур повышают стоимость кадра. Редкие задержки на всех конфигурациях не считаются полностью устранёнными только на основании короткой локальной проверки.

## Что приложить к bug report

Версию плагина и commit SekaiPOP, версию Quickshell/Qt/Hyprland, GPU и renderer, масштаб и число мониторов, шаги воспроизведения и относящийся к сбою фрагмент журнала. Для анимации полезно короткое видео. Не прикладывайте записи музыки, токены и весь домашний каталог.
