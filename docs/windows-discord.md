# Подключение Discord

Док читает текущий голосовой канал настольного Discord. В доке видны комната или личный звонок, участники, активный говорящий и время с момента обнаружения сессии. Из дока можно переключать микрофон, отключать звук вместе с микрофоном и выходить из канала.

1. Запустите настольный Discord.
2. В Sekai Soundbar откройте **Настройки → Discord** и нажмите **Подключить Discord**. В браузере подтвердите доступ с того же аккаунта.
3. Войдите в голосовой канал или личный звонок. Статус подключения виден в **Настройки → Discord**.

В разделе **Соединение для входа** по умолчанию используется вариант **Системное**. Он берёт настройки прокси из Windows. При использовании INCY выберите **INCY SOCKS5** или **INCY HTTP** в зависимости от включённого прокси. Выбор в доке сохраняется после выключения INCY.

Если INCY выключен и при входе истекает ожидание запроса токена, выберите **Прямое** и нажмите **Подключить Discord**. В этом режиме запросы дока к Discord идут через прямое подключение. Статус указывает выбранное соединение и этап, на котором истекло ожидание.

Windows хранит разрешение Discord в зашифрованном виде для текущего пользователя и восстанавливает подключение при следующем запуске. При обновлении док использует сохранённое разрешение, выданное приложению Sekai Soundbar. Кнопка **Отключить Discord** удаляет локальное разрешение и останавливает интеграцию. Доступ приложения можно также отозвать в **Настройки пользователя → Авторизованные приложения** в Discord.

Сценарий входящего вызова запускается через **Настройки → Уведомления → Тестовый звонок Discord**. Discord RPC в этой версии обслуживает активные голосовые сессии. [Команды и события RPC](https://docs.discord.com/developers/topics/rpc#commands-and-events)

## Конфигурация сборки

Сборка использует публичный ID приложения проекта из параметра CMake `SOUNDBAR_DISCORD_APPLICATION_ID`. Для этого приложения в Discord Developer Portal должны быть настроены **Public Client**, Redirect URI `http://127.0.0.1:43827/discord/callback` и доступ к `rpc`, `rpc.voice.read` и `rpc.voice.write`. Доступ для других аккаунтов определяет Discord. [Discord Developer Portal](https://discord.com/developers/applications) · [Разрешения OAuth2](https://docs.discord.com/developers/topics/oauth2#shared-resources-oauth2-scopes)
