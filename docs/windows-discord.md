# Подключение Discord

Док читает текущий голосовой канал настольного Discord. В доке видны комната или личный звонок, участники, активный говорящий и время с момента обнаружения сессии. Из дока можно переключать микрофон, отключать звук вместе с микрофоном и выходить из канала.

1. Откройте приложение проекта в Discord Developer Portal. Discord должен разрешить этому приложению `rpc`, `rpc.voice.read` и `rpc.voice.write`. Для приложения в тестовом режиме добавьте используемый аккаунт в список тестировщиков. [Разрешения OAuth2](https://docs.discord.com/developers/topics/oauth2#shared-resources-oauth2-scopes) · [Доступ к RPC](https://docs.discord.com/developers/topics/rpc#authorize)
2. В разделе **OAuth2** включите **Public Client** и добавьте Redirect URI `http://127.0.0.1:43827/discord/callback`. [Discord Developer Portal](https://discord.com/developers/applications)
3. Запустите настольный Discord. Откройте **Настройки → Discord** в Sekai Soundbar, введите публичный **Application ID** и нажмите **Подключить Discord**. В браузере подтвердите разрешения с того же аккаунта.
4. Войдите в голосовой канал или личный звонок. Статус подключения виден в **Настройки → Discord**.

Windows хранит разрешение Discord в зашифрованном виде для текущего пользователя. Кнопка **Отключить Discord** удаляет локальное разрешение и останавливает интеграцию. Доступ приложения можно также отозвать в **Настройки пользователя → Авторизованные приложения** в Discord.

Сценарий входящего вызова запускается через **Настройки → Уведомления → Тестовый звонок Discord**. Discord RPC в этой версии обслуживает активные голосовые сессии. [Команды и события RPC](https://docs.discord.com/developers/topics/rpc#commands-and-events)
