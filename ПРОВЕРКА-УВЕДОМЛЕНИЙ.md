# Тест уведомлений Sekai Soundbar на Windows 11

Тестовый установщик 0.18.3 подписан сертификатом **Sekai Soundbar Test**. Этот же сертификат встроен в установщик.

1. Выбери «Выход» в трее. Если процесс предыдущей версии `SekaiSoundbar.exe` ещё виден в Диспетчере задач, заверши его там. Затем запусти `SekaiSoundbar-Windows11-x64-Notifications-Test-Setup.exe` двойным щелчком.
2. Если сертификата ещё нет в хранилище **Локальный компьютер → Доверенные лица**, установщик объяснит, что добавит его, и попросит подтверждение. После согласия появится запрос администратора Windows. При отказе установка остановится до изменения файлов программы.
3. Открой **Sekai Soundbar** из меню «Пуск». В разделе **Настройки → Уведомления** подтверди системный запрос доступа и нажми **Проверить через Центр уведомлений Windows**.

SHA-256 открытого сертификата — `47ec599555dbc1ec899237dd2f4ab2a584aac9db2294fe86c022500c80be6eeb`.

Чтобы вернуться к обычной сборке, удали тестовый док через «Установленные приложения». Сертификат остаётся в «Доверенных лицах» для повторной установки тестовой версии. Если он больше не нужен, его можно удалить в `certlm.msc`.
