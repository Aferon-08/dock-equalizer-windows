# Тест уведомлений Sekai Soundbar на Windows 11

Тестовая сборка 0.17.1 подписана сертификатом **Sekai Soundbar Test**. Подпись нужна для регистрации служебного пакета, который позволяет запросить доступ к уведомлениям приложений.

1. Скачай `SekaiSoundbar-Test-Publisher.cer` и `SekaiSoundbar-Windows11-x64-Notifications-Test-Setup.exe`.
2. Открой сертификат и нажми **Установить сертификат**. Выбери **Локальный компьютер → Поместить все сертификаты в следующее хранилище → Доверенные лица**. Windows может запросить права администратора для этого действия.
3. Закрой запущенный док через значок в трее и запусти тестовый установщик. Затем открой **Sekai Soundbar** из меню «Пуск».
4. Подтверди системный запрос доступа. Если он ещё не появился, открой **Настройки → Уведомления → Разрешить уведомления приложений**.
5. Нажми **Проверить через Центр уведомлений Windows**. Для проверки внешнего приложения дождись его нового уведомления.

SHA-256 открытого сертификата — `47ec599555dbc1ec899237dd2f4ab2a584aac9db2294fe86c022500c80be6eeb`.

Подпись EXE приложения, MSIX и установщика проверена до публикации. Регистрация пакета и разрешение требуют проверки на Windows 11.

Чтобы вернуться к обычной сборке, сначала удали тестовый док через «Установленные приложения». После этого сертификат **Sekai Soundbar Test** можно удалить из «Доверенных лиц» в `certlm.msc`.
